# Drills

도메인별 10분 내 풀이 연습. 각 문제는 실제 시험 문항 1개 수준. 정답은 `<details>` 접힘.
클러스터: `./bin/q cluster up` 으로 만든 kind 클러스터(context `kind-cka`) 사용. 각 파일 상단의 준비 명령을 먼저 실행.

| 파일 | 도메인 | 비중 |
|---|---|---|
| `troubleshooting.md` | Troubleshooting | 30% |
| `cluster.md` | Cluster Architecture | 25% |
| `networking.md` | Services & Networking | 20% |
| `workloads.md` | Workloads & Scheduling | 15% |
| `storage.md` | Storage | 10% |

규칙: 문서(kubernetes.io)만 보고 풀기. 5분 넘으면 정답 보고 다시 처음부터 타이핑.
